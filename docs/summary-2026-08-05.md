## 恢复方法（另见 restore.md）
1. Docker：`docker compose -f server/docker-compose.yml -f docker-compose.fusion.yml up -d --force-recreate`
   （镜像从 ghcr.nju.edu.cn 拉取，WARP CA 已挂载）；
2. 网关：`python gateway/fusion_gateway.py --transport http --host 0.0.0.0 --port 8010` + 托盘；
3. 固件：`esptool ... write_flash 0x410000 firmware/xiaozhi.bin`（app-only）；
4. 机器人配置 WebSocket URL 指向 tailnet 域名。
